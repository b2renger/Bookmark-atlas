Bookmark Atlas

Group by topic

Bookmarks that use related words in their title, summary and tags are grouped together. “Auto” tries several numbers of groups and keeps the one where groups are best separated. Each run is kept, so you can compare them.

Clean the collection

Each script proposes changes. Preview shows them without writing anything; untick what you do not want, then apply. A backup is made before every run, and any run can be undone from the history below. The order shown is a good order to run them in.

1Notion token

Create a token in Notion's Developer portal. A personal access token sees what you can see, with nothing to share. An internal connection token only sees the pages and databases shared with that connection. The token is stored on this computer, outside the bookmark database.

    Where your data lives

    Everything is in this one folder: your bookmarks, your grooming scripts, the backups and the Notion token.

    To move to another computer, copy this folder there, then pick it with the menu Atlas > Choose data folder…. The same menu moves your data to another place on this computer, such as a synced drive. Because the folder holds your Notion token, do not hand it to someone else: to share bookmarks, use Export selection.

    Import a file

    Two kinds of file: a CSV export of your table from Notion (••• menu, Export, CSV), or a bundle exported from another Atlas (“Export selection” in Bookmarks). No token needed. Links already in the collection are not duplicated.
