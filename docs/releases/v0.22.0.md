## Bookmark Atlas 0.22.0: import straight from your browsers

- **Settings ▸ Import from a browser on this computer:** press *Look for browsers* and Atlas lists every profile of Chrome, Edge, Brave, Vivaldi, Opera, Chromium, Arc, Firefox (and LibreWolf, Waterfox, Zen) and Safari that has bookmarks. *Preview*, then *Import*.
- Folder names become tags, Firefox tags stay tags, and the day a bookmark was added becomes its save date. Importing the same profile again adds only what is new.
- The browser is only read, never changed, and only its bookmarks: no history, no passwords.
- If a browser is not listed, or Safari refuses (macOS asks for Full Disk Access), exporting its bookmarks to a file and importing that file still works.

Tested on profiles built in each browser's layout, not on real installed browsers: tell me if one of yours is not found or reads wrong.
