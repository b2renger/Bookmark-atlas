## Bookmark Atlas 0.26.1: four fixes from an independent review

Three reviewers that had not seen the code being written went through the whole project. This release fixes the four findings that could lose or expose data. The others follow in 0.27.0.

- **Your keys were in a plain file in the data folder.** The app said "keychain", but the installer did not contain the keychain package, so the Notion token and every model password or API key were written to `secrets.json` beside your bookmarks, and travelled with that folder when it was synced or copied. Now: the keychain package is bundled; where no keychain answers, the file is kept in the app's own folder, never in the data folder; "Copy my data" no longer copies it. **At its first start this version moves what it finds and deletes the old file.** Settings says which place is used. *If your data folder was synced, copied or shared while it held keys, renew them (Notion integration token, provider API keys).*
- **"Select all N" ignored the filter bar.** With a tag, site or date filter on, it selected the whole collection, and Delete or Add tag then acted on everything. It now selects exactly what the list shows, and says so.
- **Workspaces vanished after an update.** Only the main collection was upgraded when a version changed the database; older workspaces stopped being listed. They are now upgraded when listed or opened. Nothing was deleted: workspaces that vanished come back.
- **Adding a second connection lost the first one's password** (introduced in 0.26.0). The old password now stays with its connection.

Also:

- A kept password is only reused for the address it was typed for; asking to reuse it for another address is refused before anything is sent.
- A password, key or token is never sent on after a redirect: the request stops with a message.
- Connections (addresses, models) are kept beside the keys, not in the data folder, so a folder received from someone cannot redirect your keys.
- A database upgrade is now applied whole or not at all; an interrupted one no longer blocks the file.

**Checked:** 359 automatic tests (18 new, each written to fail on the old code), and browser runs. The release build prints whether the bundled Python reaches the keychain on each platform. **Not checked:** the keychain on a real Windows, macOS or Linux desktop session with a person signed in.
