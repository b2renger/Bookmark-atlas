## Bookmark Atlas 0.17.0: clearer grid names, and the 3D views in plain sight

- **Grid:** cells no longer repeat the same name. Each is now named by the tag that sets it apart from the others; point at a name for the cell's other tags.
- **Map:** the five arrangements are now buttons above the picture, always visible: Similarity, Timeline, Grid, **Space and time · 3D** and **Links · 3D**. Draw the map once, then press one.
