## Bookmark Atlas 0.2.0: import and grooming

First release. Covers phases 0 to 2 of the plan.

**What you can do**

- Import your bookmarks from a Notion CSV export, or directly from Notion with a token.
- Browse and search them: titles, summaries, links, tags, platform.
- Clean the collection in the Grooming tab: merge duplicates, merge tag spellings, set platforms, fix dates. Every script previews first, backs up before writing, and can be undone.
- Select several bookmarks to add or remove a tag, delete them, or export them as a file.
- Share: "Export selection" writes a bundle file that another Atlas user imports from Settings.
- Add your own grooming scripts in the `scripts` folder of the data folder.

**Good to know**

- The Notion token import has not been tried with a real token yet. Use Preview first.
- Your data is in `%APPDATA%\\Bookmark Atlas`. Updates and uninstalling leave it alone.
- Not there yet: clustering, the map and the other visual views.
