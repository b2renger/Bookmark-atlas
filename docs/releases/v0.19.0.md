## Bookmark Atlas 0.19.0: import a database dump, and room for fifteen thousand bookmarks

- **New import: a database dump** (an `.sql` file written by phpMyAdmin or mysqldump for a site that kept links). In Settings, *Import a file*: preview what it holds, then import. It always goes into a **new workspace**, so your collection is not touched.
- **Only bookmarks are read:** link, title, description, date added and tags. Accounts, authors, e-mail addresses and passwords stay in the file.
- **Old damage is repaired on the way in:** broken accents (“ScÃ©nographie”), the same link saved several times, text cut at the width of its column, tags used only once.
- **Large collections:** the map, the threads and the 3D views now work on about 15,000 bookmarks. Above 3,500 the map places a sample exactly and sets the rest among it.
- Threads over many years show one mark a year.

Tried on one real dump (a MariaDB export). Other sites' tables are recognised by their column names and may need adjusting.
