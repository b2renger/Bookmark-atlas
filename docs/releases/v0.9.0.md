## Bookmark Atlas 0.9.0: publication dates read from the pages

- **Grooming → Look up publication dates.** For each bookmark without a publication date, the app opens the page and reads the date the page declares for itself. For a GitHub repository it takes the day the repository was created. You see the progress and can stop at any time.
- The lookup changes nothing by itself. What it finds is proposed by the script **Publication date read from the page**: preview, untick what you do not want, apply, and undo from the history if needed.
- New script **Remove publication dates from one source**, for example the dates taken from the unverified Date column of the import.
- X posts are left out (their date already comes from the post ID). If GitHub asks to slow down, run the lookup again later for the remaining repositories.

This is the first version that reads the bookmarked pages. It has been tested with stand-in pages, not yet against the real sites: tell me what it finds on yours.
