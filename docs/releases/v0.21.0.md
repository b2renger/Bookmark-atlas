## Bookmark Atlas 0.21.0: then and now, tags that mean the same, and a tutorial for the model features

- **Compare then and now** (Grooming): for bookmarks that have a summary, the model says whether the page still matches it, has moved on, or is now something else. The verdict shows in the side panel, and a new script tags “page changed” and “page replaced”.
- **Find tags that mean the same** (Grooming): the model groups synonyms, translations and abbreviations; a new script proposes each merge for you to tick.
- **Side panel:** shows the model's verdict on the page and any summary it proposed that you have not applied yet.
- **In-app tutorial:** a four-step tour “Going further with a language model” on the Bookmarks tab; the Grooming card now lists four jobs, each saying what it does and which script follows; the Guide has first-time steps, an explanation of each feature, what is sent, and what to do when something fails. The `?` button on Ask opens it.

Like 0.20.0, the model features are tested against a stand-in farm, not a real one.
