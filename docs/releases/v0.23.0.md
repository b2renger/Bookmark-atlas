## Bookmark Atlas 0.23.0: Claude, OpenAI, Gemini or Mistral with an API key

- **Settings ▸ Language models ▸ Where the model runs:** besides a model on your own network, choose **Claude (Anthropic), OpenAI, Gemini (Google) or Mistral**, paste your API key, press *Test*, pick a model, *Connect*. Ask, summaries and tags, then-and-now, tag merges, topic names and “why?” then work the same.
- **Vectors** (“Place bookmarks by meaning”) are available with OpenAI, Gemini and Mistral. Claude offers none: the map and topics keep comparing words.
- **What changes with a provider:** what Atlas sends leaves your computer and goes to that company, and each request is billed to your key. The card says so before you connect. Start with a selection before running summaries on thousands of bookmarks.
- The key is kept in the system keychain, never in the database, a snapshot or an export, and is only ever sent to the provider's own address.

Tested against stand-in servers, not the real providers: I had no key to try with. If Test fails with your key, send me the message it shows.
